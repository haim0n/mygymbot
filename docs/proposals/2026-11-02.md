# Product round 2026-11-02: gym beginners

Focus, set by Haim in a brainstorm: make the app simple for gym beginners, who need to be told what to do. This round
has only his two picked items. The look-and-feel guide that a first round normally proposes moves to the next round.

## What I looked at

- The code of the live workout (`log.jsx`, `rest-timer.jsx`, `tour.jsx`, `exercises.jsx`, `workout.js`), DESIGN, ROADMAP and the 33 GitHub issues (#6 and #30 touch this round).
- Usage: the bucket holds only Haim's file (19 workouts, 8 of them imported; 2 plans; last workout 2026-11-01). There are no friends' files and no `feedback.jsonl`. So there is **no beginner usage data**. Haim's file gives one baseline: since 2026-10-14, his first workout with set feel, he rated 107 of 121 sets (88%).
- Screens at 393 px: Haim's data (`../../.pm/2026-11-02/now/`), and a made-up beginner "Dana" with a coach plan A and no workouts (`../../.pm/2026-11-02/beginner.json`, `../../.pm/2026-11-02/now-beginner/`).
- The market: Fitocracy Playback, StrengthLog focus mode, Strong and Hevy for beginners, a Trainerize feature request, a PureGym survey, and Chameleon's product tour benchmarks (sources at the end).

## Proposals

### 1. Guided workout: one set at a time for beginners

**Problem.** A beginner's first workout opens as a long form. Plan A from the coach gives 5 exercises x 3 sets: 15 empty weight boxes, 15 check circles and 4 link rows (see `now-beginner/workout.png`). Plan tags carry names only, so the app knows no weight. A tick on an empty box saves the set at 0 kg, which the app reads as bodyweight, also for a dumbbell lift. The rest bar then says "Next set 8 reps", with no weight (`now-beginner/resting.png`). Nothing on the screen tells the beginner which weight to take, or that the app corrects it later.

**Evidence.**
- Screens: `../../.pm/2026-11-02/now-beginner/workout.png` (the form), `../../.pm/2026-11-02/now-beginner/resting.png` (the rest with no weight).
- Code: `rateSet` moves only the sets at the rated weight. An empty set counts as 0 kg, so after "Too easy" on a 12 kg set 1, sets 2 and 3 stay empty. The list view shows it: `../../.pm/2026-11-02/guided/list-tour-rest-1.png` (set 1 at 12 kg, "Next set 8 reps").
- No beginner usage data exists (one user, Intermediate).
- Market:
  - Fitocracy Playback took the athlete through a workout set by set: each screen showed only the exercise, the weight and the reps, and a check moved on to the next set. It was optional; the normal log stayed.
  - StrengthLog has a focus mode: a simplified version of the same workout view, larger type, and you leave it to edit and come back.
  - Reviews call Strong a logger with "zero guidance" for beginners, and Hevy "a logger, not a coach". MyGymBot already has the coach plan and Autopilot; it lacks the screen that tells the beginner what to do now.
  - Nike Training Club plays one exercise at a time, with a demo video and a timer, and skip and pause controls.
  - A Trainerize user asked for "a full screen view exercise by exercise" (5 votes, 2021).
  - PureGym: 64% of the people asked did not know how heavy their weights should be.

**Smallest version.** A second view of the same live session, not a second workout system. No new storage key and no AI call.
- Who: `profile.experience === "Beginner"` and a workout with exercises in it (`wantsGuided`, workout.js). "Full list" in the guided view and "Guide me, one set at a time" in the list switch between the two views; the choice is App state for this app session (see open question 3).
- The screen (`GuidedWorkout`, log.jsx, in place of the whole Workout tab during a workout):
  - "Workout A, exercise 1 of 5" and a "Full list" link.
  - The start and finish pictures, with "How to do it" (opens the existing details sheet: muscles, video, Check my form).
  - The name and one line: the coach's cue for this exercise once there is one, else "Works quads and glutes, with hamstrings and core." (`describeMuscles`, no AI).
  - "Set 1 of 3" with a bar per set, then "Do 8 reps at 12 kg", "The weight is per dumbbell." for dumbbell lifts, and "Change weight or reps" (opens the existing `SetRow`). Barbell lifts can show the plates per side (`describeNextSet`).
  - A large Done. It starts the rest bar, as a tick does.
  - During the rest: the picture shrinks to a thumbnail, and "How was the set you just did?" with the three feel buttons sits above the next set's Done. The result line ("Too easy: the next sets go up.") and the new weight show at once.
  - After the last set: "That was the last set" and "Finish and save 15 sets" (the existing finish screen follows).
- An empty weight: "Do 8 reps", "Pick a weight you could lift 12 times." (reps + `GUESS_EXTRA_REPS`, 4, config.js), a weight field with "kg per dumbbell", and "Not sure? Start light. After the set, you say how it felt, and the weight changes to match." Done waits for a weight (open question 2). Bodyweight lifts ask for no weight.
- `carryWeight` (workout.js, unit-tested on the branch): a weight typed on a set fills the exercise's later empty sets, so set feel can move them. The mockup calls it only from the guided Done; the build should call it on every tick, in the list too (open question 7).
- Files: `src/workout.js`, `src/config.js`, `src/ui/log.jsx`, `src/App.jsx`, `tests/domain.test.mjs`, an e2e test in `tests/e2e/workout.test.mjs` (a beginner's first workout: empty weight, Done, feel moves the next set, Full list shows the same session, finish), and the Live workout section of `docs/DESIGN.md`.

**Success measure.** What the data files can show, for each beginner's first 3 workouts:
- No set at 0 kg on a lift that needs a weight (on master, every set ticked with an empty box is one).
- About 3 sets saved per exercise (the plan's 3).
- Set feel on 80% or more of the sets (Haim's baseline: 88%).
- A second workout within 7 days of the first.
- First, beginners must exist: Haim invites 2 or 3 friends who are new to the gym (open question 10). Taps on "Full list" are not stored, so the round does not promise to count them.

**Cost.** None: no AI calls. The coach's cue on the screen is the rest note that the app already asks for.

**Removes or simplifies.** No code goes away: the mockup adds about 160 lines in `src/`, most of them the screen in log.jsx. For the beginner, the live workout drops from about 10 controls per exercise (2 fields and a tick per set, Replace, Remove, Add set, Remove last set, Mark all done) plus Up next and History to one button. It also makes item 2's tour 1 card instead of 3 for beginners.

**Mockup.** Branch `mockup/guided-workout`, worktree `../mygymbot-mockup-guided-workout`, commit `b3d8c19`. Screens at 393 px, Dana's first workout (the coach lines in the rest bar are real Gemini replies):

- After:
  - `../../.pm/2026-11-02/guided/guided-set-empty.png`: the first set, no weight yet, Done waits.
  - `../../.pm/2026-11-02/guided/guided-set-typed.png`: 12 kg typed.
  - `../../.pm/2026-11-02/guided/guided-resting.png`: the rest bar with the coach's cue, the feel question, the next set at 12 kg (carried).
  - `../../.pm/2026-11-02/guided/guided-feel.png`: "Too easy": the next set is now 14 kg.
  - `../../.pm/2026-11-02/guided/guided-set-2.png`: set 2; the cue moved from the rest bar to the line under the name.
  - `../../.pm/2026-11-02/guided/list-with-guide-link.png`: Full list shows the same session (12 done, 14 and 14 to do).
  - `../../.pm/2026-11-02/guided/guided-last.png`: after the last set.
- Haim's own screens do not change: he is Intermediate (`../../.pm/2026-11-02/now/workout.png`).

**Seen while mocking up.** "Goblet Squat (Dumbbell)" shows a drawing with a kettlebell. In the guided view the picture is the main instruction, so a beginner looks for a kettlebell. The drawings of a beginner's first plans need one check against their names before the build.

### 2. First-workout tour and beginner rest cues

**Problem.**
- The first-time tour covers only the tabs. In the first live workout nothing says that a tick starts the rest, what -15, +15 and Skip do, or that Too easy and Too hard change the weight. In the list view, the set feel row is the app's own idea; Strong and Hevy have nothing like it.
- The coach's rest note turns through 4 kinds (`REST_NOTE_KINDS`): a cue, a question, the set's numbers, a fact. A beginner needs the cue. A fact about the muscle, or a question, is one more thing to read and does not help them do the next set.
- The Workout card of the app tour says "the app sets the weights". In a first workout it does not: the boxes are empty.

**Evidence.**
- The tour was designed together with item 1. The guided screen already says, in its own words: what to do now (Do 8 reps at 12 kg), how to say it is done (Done), how to guess a weight, that set feel changes the weight (the hint, the question, the result line), and what comes next. What it does not say: the rest bar's -15, +15 and Skip, and that the rest chimes.
- So the tour is 1 card in the guided view and 3 cards in the list view:

  | Card | When | Guided view | Full list |
  |---|---|---|---|
  | Tick each set (on the first check circle) | the workout's start | no: Done says it | yes |
  | Your rest (on the rest bar) | the first rest | yes | yes |
  | How was it? (on the feel row) | the first rest | no: the question says it | yes |

- Chameleon's benchmarks: 3-step tours had a 72% completion rate, 7-step tours 16%; completion falls fast after 5 steps.
- The first rest note of a workout is already a cue (kind 0). The real beginner cues in the mockup were good: "Keep your chest tall and drive smoothly through your whole foot on the way up." From the second exercise on, the turn moves to a question or a fact.
- No beginner usage data exists.

**Smallest version.**
- Rest cues: `restNoteRequest(session, name, chat, cueOnly)` pins the kind to "a cue for the next set"; `useRestNote` passes `cueOnly` for beginners (workout.js, rest-timer.jsx, a unit test). Still one note per exercise, at its first rest, and still one thing to read in the rest bar. Quiet and Reply stay.
- Tour: `WORKOUT_TOUR_STEPS` (config.js), with `at` (start or first rest) and `listOnly`. `SpotTour` (tour.jsx) is the existing tour card, put on a part of the screen with the rest dimmed; Next, Skip (ends the whole tour), Android's Back skips. It shows only in the athlete's first workout (no workouts saved), once (`settings.workoutTourSeen`, optional, like `tourSeen`).
- The Workout card of the app tour: "Start a workout here. The app tells you each set: the weight, the reps and the rest." (`TOUR_STEPS`, config.js).
- Checks:
  - `scripts/coach_eval.mjs`: a rest-note pair. A beginner's second exercise must get a cue; an intermediate athlete's second note must not be forced to a cue. Run the beginner one twice.
  - Add a rule to `onboarding-equipment`: the profile tag has `experience: Beginner` ("None, I'm a beginner"). Item 1 depends on it.
  - e2e: the first workout shows the tour once; other e2e tests that start a workout with no workouts seed `workoutTourSeen: true`.
- Files: `src/workout.js`, `src/ui/rest-timer.jsx`, `src/config.js`, `src/ui/tour.jsx`, `src/App.jsx`, `tests/domain.test.mjs`, `scripts/coach_eval.mjs`, `tests/e2e/workout.test.mjs`, `docs/DESIGN.md` (data model, Onboarding, Coach between sets).

**Success measure.**
- The coach-eval pair passes in 2 of 2 runs.
- In the list view, set feel on 80% or more of the sets of a new athlete's first workout.
- The data file can't show tour completion, Quiet or Skip (the session is deleted at finish). So, after the first beginner friend's first workout, Haim asks one question: "Did anything need explaining?"

**Cost.** No extra AI calls: the beginner gets the same one rest note per exercise, only of one kind. The tour makes no calls.

**Removes or simplifies.** The guided view removes 2 of the 3 tour cards for beginners. The mockup adds about 75 lines in `src/`, 49 of them `SpotTour`. `REST_NOTE_KINDS` stays; beginners use only its first kind.

**Mockup.** Same branch, commit `cc0f7ed`.
- Guided view, 1 card: `../../.pm/2026-11-02/guided/guided-tour-rest.png`.
- Full list (a new athlete "Sam", Intermediate, `../../.pm/2026-11-02/new-intermediate.json`):
  - `../../.pm/2026-11-02/guided/list-tour-start.png`: Tick each set.
  - `../../.pm/2026-11-02/guided/list-tour-rest-1.png`: Your rest, 1 of 2.
  - `../../.pm/2026-11-02/guided/list-tour-rest-2.png`: How was it?, 2 of 2.

## Open questions

1. **A skipped interview.** The default experience is Intermediate, so someone who skips the coach interview never gets the guided view. My recommendation: keep the default. A skipper has no plan (plans come from the interview), so they start an empty workout and pick their own exercises: they know what to do, and the guided view would have nothing to guide. A beginner gets a plan and `experience: Beginner` from the interview (an eval rule checks the tag). The alternative: take experience out of `DEFAULT_SETTINGS`, and read "not set" as Beginner (guided). Existing users keep their stored Intermediate. The Profile select and the coach line then need a "not set" case. Which one?
2. **Done with an empty weight.** The mockup keeps Done off until a weight is typed. The other way: Done always works, and an empty weight saves 0 kg, which is wrong for a dumbbell lift. Keep Done off?
3. **Where "Full list" lives.** The mockup keeps it in App state: it lasts until the app closes, and a reload brings back the guided view. Other places: the session (like Quiet; it lasts for this workout), or a Profile setting (it lasts for good). Which one?
4. **The rest bar's "Next set" line** repeats the guided screen's "Do 8 reps at 14 kg". The smallest version keeps the rest bar as it is. Hide that line in the guided view?
5. **The cue arrives after set 1.** The rest note comes at the first rest of each exercise, so set 1 of each exercise shows the muscles line, not a cue. For beginners, the note can come in the rest before the exercise instead, with the same number of calls. Worth it now, or later?
6. **The guided tour card.** One card is left: the rest bar. The guided rest screen could say "It chimes when the next set is due" itself; then the guided view needs no tour at all. Keep the card, or write it into the screen?
7. **`carryWeight` in the list view too.** It fixes "Next set 8 reps" and the 0 kg saves for everyone, in about 2 lines. Include it in this build?
8. **The kettlebell drawing for Goblet Squat (Dumbbell).** Redraw it, or rename the plan exercise to Goblet Squat (Kettlebell) where the coach writes it?
9. **The look-and-feel guide.** Confirm that it goes into the next round.
10. **Beginner testers.** Item 1's measures need 2 or 3 friends who are new to the gym. Who, and when?

## Decisions

2026-11-02, Haim:

- **1. Guided workout: approved.** Issue #34.
- **2. First-workout tour and beginner rest cues: approved.** Issue #35.
- Q1, a skipped interview: keep the default Intermediate. A user who skips the interview has no plan, so the guided view has nothing to show.
- Q2: Done waits until a weight is typed. Bodyweight lifts ask for no weight.
- Q3: "Full list" is kept in the session, like Quiet. It lasts for this workout and survives a reload; the next workout starts guided.
- Q4: the guided view hides the rest bar's "Next set" line, so the coach's cue is the one thing to read.
- Q5: the cue before set 1 comes later, if beginner testers miss it.
- Q6: the guided rest screen says "It chimes when the next set is due" itself. The guided view has no tour; the tour shows only in the full list (3 cards).
- Q7: `carryWeight` runs on every tick, in the list view too, for every user.
- Q8: a new drawing for "Goblet Squat (Dumbbell)" with its own photo id (about $0.07, checked by eye). `Goblet_Squat` stays the kettlebell picture.
- Q9: the look-and-feel guide goes into the next round.
- Q10: Haim picks 2 or 3 beginner testers after the build is deployed.
